# 雾海对弈 · FOGBOUND

《雾海对弈》是一款 Windows 海战战术游戏。你将在迷雾中布阵、侦察，再用战术卡下达命令。游戏包含六十关单人战役、自由演习和局域网双人对战。

- [宣传网页与战斗演示](https://saoker-liu.github.io/FOGBOUND/)
- [下载 v1.0.0 · Windows x64](https://github.com/Saoker-Liu/FOGBOUND/raw/refs/heads/main/FOGBOUND-v1.0.0.exe)
- [版本说明](https://github.com/Saoker-Liu/FOGBOUND/releases/tag/v1.0.0)

网页在 `docs/` 下，由 GitHub Pages 发布。画面取自游戏原画、游戏内卡牌与战斗效果录制。字体许可随网页素材提供。
